# **Accommodation Booking Platform**

## **Overview**

The **Accommodation Booking Platform** is a Java-based application designed following the principles of **Object-Oriented Programming (OOP)**.
It provides a complete environment for **managing accommodations**, **searching and booking** by customers, and **system supervision** by administrators.

The project emphasizes **modular architecture**, **extensibility**, and a **clear separation** between business logic and the user interface *(GUI)*.

---

## **Functionality**

### **User Roles & Capabilities**

* **Accommodation Providers**:

  * Add, edit, and delete their own accommodations.
  * View reservations and cancellations related to their properties.

* **Customers**:

  * Search accommodations using filters (price, availability, amenities).
  * Make and cancel reservations.
  * View booking history.

* **Administrators**:

  * Monitor users and accommodations.
  * Manage new provider registration requests.
  * Communicate directly with users when needed.

---

## **Technical Features**

### 🔹 **Data Storage**

* Persistent storage of users, accommodations, and reservations using files.
* Structured file management that allows easy data retrieval and updates.

### 🔹 **Security & Access Control**

* Registration and login system with authentication.
* Role-based access permissions for different user types.

### 🔹 **Extensibility & OOP Principles**

* Designed using **inheritance**, **polymorphism**, and **encapsulation** to ensure flexibility and scalability.
* Easily extendable to include new accommodation types (e.g., caravans, beachfront villas) without altering the system’s core logic.

### 🔹 **Testing & Code Quality**

* **JUnit** tests implemented for critical system functionalities.
* **CodeMR** used to evaluate and improve code architecture.
* Complete documentation using **JavaDoc** for maintainability and clarity.

### 🔹 **Development & Collaboration**

* **Agile Development**: Iterative development starting from a Command-Line Interface (CLI) and later expanded into a Graphical User Interface (GUI).
* **GitHub Integration**: Private repository used for version control and collaborative development.
